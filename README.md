# Psicopatologia Especial · ETP1

Estudo interativo: 22 blocos, 57 questões e 55 flashcards, com casos, comparativos, glossário, caderno de erros e simulados de 8 objetivas + 4 abertas.

## Conteúdo e fontes

- Base dos slides até 03/09, preservada e identificada.
- Aula de 10/09 e ETP2 excluídos.
- Complementos sobre temas indicados para ETP1, com fontes identificadas no próprio HTML: personalidade, saúde mental, reforma psiquiátrica, direitos e referências do CFP.
- As apresentações dos grupos e os debates de sala não foram disponibilizados. Os complementos não pretendem reproduzi-los.
- Respostas-modelo e vinhetas novas são didáticas, não gabaritos oficiais nem avaliação clínica.

## Usar

Abra o endereço do GitHub Pages no navegador. No iPhone, abra o link no Safari; a prévia de um arquivo recebido por aplicativos pode não executar o estudo interativo.

O arquivo `index.html` também funciona offline em um navegador que permita abrir HTML local. O conteúdo, os exercícios e as imagens estão no próprio arquivo. Somente os links para consultar as referências externas exigem internet.

O progresso é salvo no navegador e no endereço usado. Cada pessoa mantém seu próprio histórico; não existe envio de respostas a um servidor. Em “Caderno de erros” ou “Fontes e cobertura”, exporte o progresso para levar a outro navegador ou endereço.

## Publicar no GitHub Pages

Envie `index.html`, `.nojekyll` e este README para a raiz do repositório público. Em Settings → Pages, selecione Deploy from a branch → main → / (root) → Save. Aguarde a publicação e use o endereço mostrado pelo GitHub.
